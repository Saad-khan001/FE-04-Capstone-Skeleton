# FE-04 Capstone Skeleton Project

A modern Next.js 15 capstone skeleton application built with **App Router**, **TypeScript**, and **Tailwind CSS v4**.

## 🚀 Key Features

- **App Router Architecture:** Modern layout hierarchy with sticky navigation bar.
- **Responsive Layout:** Optimized for mobile (375px) and desktop (1280px) viewports using Tailwind CSS.
- **Placeholder Routes:** Active route setup for `/dashboard` and `/settings`.
- **Health Check Route:** Server-side fetched API data display at `/health`.
- **Environment Config:** Configured with `.env.example` structure.

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Deployment:** Vercel
